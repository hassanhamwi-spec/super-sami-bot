# Super Sami — حالة التنفيذ

هذه الحزمة أساس آمن قيد الإعداد، وليست مساعد Hermes مكتمل التشغيل.

## الأجزاء
- `index.js` و`hermes.js`: مدخلان لنفس بوابة HTTP لتفادي اختلاف أمر تشغيل Render.
- `src/gateway.js`: توثيق Meta، توقيع HMAC، حصر المرسل والرقم، وحدود حجم الطلب.
- `hermes-runtime`: إعداد أولي مقيد لمحرك NousResearch/Hermes الحقيقي؛ ليس نسخة محرك مضمنة ولا نموذج ذكاء مثبتاً.
- `storage`: أرشيف نصوص اختياري لـAstra DB؛ منفصل عن جلسات Hermes، ولم يُختبر بحساب حي.

## التشغيل والفحص
يلزم Node.js 22 أو أحدث وPython 3 للاختبارات الخاصة بالتخزين.

```sh
npm test
python3 -m unittest discover -s storage -p 'test_*.py' -v
python3 -m unittest test/test_cloud_db_probe.py -v
npm start
```

لفحص اتصال PostgreSQL/Neon بصورة مستقلة، ثبّت `requirements-probe.txt` داخل بيئة Python معزولة، وضع `DATABASE_URL` في متغير البيئة فقط، ثم شغّل `python3 cloud_db_probe.py`. يرفض الفحص اتصالاً لا يفرض TLS، وينفذ `SELECT 1` فقط، ولا يطبع عنوان الاتصال أو اسم المضيف أو المستخدم أو قاعدة البيانات.

داخل Render اختر Docker من هذا الفرع، ومجلد الجذر فارغ، وHealth Check Path هو `/healthz`. اختر الخطة المجانية فقط. عند بدء الحاوية يشغّل الأمر `cloud_db_probe.py` من متغير `DATABASE_URL` السري؛ لا يبدأ خادم Node إلا بعد نتيجة `PASS`. خزّن المتغيرات الموجودة في `.env.example` في إعدادات البيئة السرية، لا في GitHub. رمز التحقق مطابق بين Render وMeta.

`GET /webhook` يعيد قيمة `hub.challenge` نصاً عند تطابق الرمز و`hub.mode=subscribe`. لا يكفي كود 200 وحده لإثبات التوثيق.

`GET /healthz` يعرض رقم النسخة وcommit المنشور. `GET /readyz` يعيد 503 حالياً، لأن معالج الرسائل غير موصول. طلبات الرسائل لا تُقبل بنجاح كاذب. هذه البوابة لا ترسل رسائل ولا تستدعي مزود ذكاء ولا تنشئ موارد مدفوعة.

## حدود مهمة قبل التشغيل الحقيقي
منع التكرار في الذاكرة فقط؛ يلزم طابور دائم قبل ربط أعمال طويلة أو ذات أثر خارجي. التخزين الدائم ونموذج الذكاء والصوت وربط الرقم غير مكتملة. لا تضع هذه الحزمة محل نظام رسائل إنتاجي نشط قبل تجهيز المعالجة. لا توجد ضمانة تشغيل دائم مجاناً ولا ضمانة توفر صوت Gemini خارج تطبيقه.

لا ترفع معلومات صاحب الحساب أو مفاتيحه أو سجل محادثاته إلى هذا المستودع العام. إعداد الشخصية عام عمداً؛ تضاف المعلومات الخاصة فقط إلى تخزين خاص بعد موافقة صاحب الحساب.
